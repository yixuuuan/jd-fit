# 示例：阶段 0 输出

> 虚构候选人：连锁酒店运营经理，7 年，旅游管理本科，管理 30 人前厅团队，日常使用酒店管理系统（PMS）和 OTA 后台，无 SaaS 公司经验。
> 目标岗位：某酒店 SaaS 公司「客户成功经理」。

**结论：B 级，改后投。行业经验是加分项，缺口在 B2B 续费指标的语言。**

| 要求 | 类型 | 状态 | 说明 |
|---|---|---|---|
| 本科及以上 | 基本 | ✓ | 旅游管理 |
| 3 年以上客户服务或客户管理经验 | 基本 | ✓ | 7 年，含投诉处理与大客户接待 |
| 熟悉 SaaS 产品或 B2B 业务 | 基本 | ✗ | 只做过使用方，没做过供应方 |
| 数据分析，理解续费率、净收入留存（NRR）等指标 | 基本 | △ | 熟悉入住率、RevPAR，指标逻辑相通，2 周可补 |
| 酒店或零售行业客户经验 | 加分 | ✓ | 本身就是目标客户画像 |
| CRM 工具使用经验 | 加分 | △ | 用过会员系统，未用过 Salesforce 类工具 |
| 英语工作能力 | 加分 | △ | 可读写，口语一般 |

**打分：** 方向 18 / 能力 20 / 年限 13 / 资质 8 / 地点 10 / 语言 7 / 偏好 4 = 80
**封顶：** 基本要求 1 项 ✗ → 最高 79，不能评 A。最终 79，B 级。

**改写方向：** 把"使用 PMS"重写成"推动门店上线新系统、培训员工、反馈产品问题"。这是客户成功经理每天站在对面看到的事。
